^ - "it's start point of row"
$ - "it's end point of row"

. - "any one simbol"

[] - "set of simbols"
[abc] -  search a or b or c
[0-9] - search any digit
[a-z] - search any lower letter

+ - 1 or infinite time ' yes+ (find yesssss, but not ye) '
* - 0 or infinite time 
? - 0 or 1 time 

{n} - n times 

\d - any digit = [0-9]
\w - any letter, digit or '_' = [a-zA-Z0-9_]
\s - any space
